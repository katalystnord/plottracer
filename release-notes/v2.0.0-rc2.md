# PlotTracer v2.0.0-rc2

The second release candidate for v2.0. Everything in
[rc1](https://github.com/katalystnord/plottracer/releases/tag/v2.0.0-rc1) -
the bar interval model, pie and donut charts, spider charts, the multi-format
importer - plus one new surface and six fixes.

## New: press F1

**How to use PlotTracer** - a card that opens over the app with the workflow,
the ten tools *with the icons the rail actually draws*, and the keys worth
knowing. It is deliberately small and fits on one screen: it is for the moment
you are three clicks into a calibration and cannot remember which key nudges,
not a tour.

Reachable two ways on purpose. **F1** opens it; so does a button at the top of
the **?** menu, which carries the `F1` hint so the key gets learned rather than
hidden. A shortcut nobody has been told about is a feature that does not exist
for a first-time user.

The **?** menu also gains a **Manual** button, beside Take The Trace Challenge,
which opens the full manual in your browser. The manual's address had been shown
as plain text since v1.6 - and had disappeared entirely on 29 July, taken out as
collateral in an unrelated change, so v1.6.0 and rc1 both shipped with no route
to their own documentation.

## Fixed

**A pie project could reopen with every value NaN.** Pie charts store their
total in the project file. If that entry held anything other than a plain number -
a corrupt file, or one written by other software - the total came back as
"not a number", the calibration reported **success**, and every slice read NaN
while the figure and its points looked entirely normal. The pie now refuses a
total or sweep it cannot read, with the same rule the calibration panel already
applied.

**A circular chart recorder with numeric times could not be reopened.** If the
time axis used plain numbers rather than dates, the start time was written to
the file as empty, and reopening the project failed to calibrate - the figure
and every captured point were still there, with no readings. The start time is
now stored exactly as typed, so dates and numbers both survive a save.

**Exports could produce a spreadsheet that would not open.** A series or
category name containing a control character - which can arrive from an imported
project, without anyone typing it - was written straight into the `.ods` file.
Those characters are not merely awkward in XML; they are forbidden, so a
conformant reader rejects the whole workbook rather than one cell. They are now
removed. Tabs and newlines are kept, being legal.

**Zooming mid-drag could record the wrong rectangle.** While dragging a bar
capture, a crop, a region or a lasso, the zoom keys and buttons moved the view
without moving the anchor the drag started from - so the rectangle committed was
not the one drawn on screen. The wheel already refused this; the buttons, the
slider and the Ctrl +/−/0/1 accelerators now refuse it too.

**Opening a project archive is bounded.** A specially-crafted archive could
declare an enormous amount of data and be inflated on open. Archives are now
refused above a generous ceiling, and the format sniffers - which run on
*every* file you try to open - read only the one entry they need instead of
expanding the whole thing.

**A bar capture aimed at a new bar's second corner filed it as the first.** Not
reachable through the interface today, but fixed in the model rather than left
to become reachable later.

## Benchmarks

The website now carries measured results against two public corpora from the
CHART-Infographics competition series, scored with the competition's own metric,
with the corpora cited as references and the current limitations stated beside
the numbers. The harness that produces them is public and the figures are
regenerated from its output rather than transcribed.

## Notes

This is a release candidate. The macOS and Windows builds are unsigned; on first
launch macOS needs right-click → Open, and Windows SmartScreen needs
*More info → Run anyway*.
