# v2.7 workflow walk (from 2026-10-30)

David walks the workflow step by step in the built app; each step records what did not work and what should
change, in his words where possible. Only his decisions are written here. The rules it is held to (David,
2026-10-21): automatic tools live inside the existing cards and tools and produce the same objects the manual
way does; manual and automatic steps mix seamlessly. And (David, 2026-10-31): **one workflow and one UI layout
for every kind of figure** (drawn PDF, PDF page as a picture, PNG, JPEG, scan); whatever is settled holds for all of
them. (Later, not now: "PDF" becomes PDF + SVG.)

⚑⚑ **There is no separation between an automatic and a manual flow** (David, 2026-10-31: "This is really important
that you see this"). There is one card per step and, in it, ways of doing the step: a click, the guided order,
a detection. Each produces the same objects, any of them can finish or correct what another started, and nothing
records which one was used. Never write "the manual walk" or "the automatic path" as if they were two things.

## Step 3: the calibration card (the final design, David 2026-10-31)

- Just under the card's header (the fold arrow and "Calibration"), a new button: **[Automatic axis detection]**.
- After the calibration has been set, clicking the calibration tool on the left rail (the second button, the
  crosshair) unfolds the calibration card.
- If a calibration point is moved, the chart loses its calibration, and the user clicks Calibrate again, which
  closes the card. Every move counts, a one-pixel arrow-key nudge as much as a drag: "To be consistent."
- Pressing [Automatic axis detection]:
  - if no points can be found, a warning in the lower information bar says that no calibration points could be
    fixed (David's word), with the warning triangle, as every can't-go-on message;
  - every calibration point that can be detected is placed, and left there for the user to adjust if needed;
  - each detected point comes with its number, read from its label (X1 on the tick under "1000" comes with 1000
    filled in); both the point's placement and its number stay editable by the user;
  - detection works on the assumption that X1 and Y1 share a point (Common origin), so it places the origin,
    X2 and Y2;
  - a point that was not found can still be placed: the user clicks its chip in the calibration card (X2, say),
    then clicks the canvas.
- Clicking a chip and then the canvas places that point at any time, with or without a detection: "yes of course."

## Step 3b: tick marks (David, 2026-10-31)

- A fold-out section at the bottom of the calibration card, in the same place on every graph.
- Graphs that need it (category axes: bar, histogram, heatmap): a required second step, unfolding by itself once
  the calibration is set. It holds today's Categories stage.
- Graphs that do not (value axes): the section is shown in its place, GREYED OUT, and cannot be unfolded, because
  on a value axis tick marks do nothing for now ("the honest answer is nothing for now"). It stays in the layout
  because a graph type nobody has dreamt up yet may need non-exact but still value-based tick points; it ungreys
  for that type only.

## The Legend tool's card (rail 3, David 2026-10-31)

Only three buttons, top to bottom: **[Mark legend]**, **[Auto detect legend]**, **[Mask an area]**.

- Nothing that is read from the legend is shown to the user ("It will just confuse people"). What is read is
  used only to offer series names as suggestions, and by the internal tools to help the automatic series
  detection.
- The only thing shown is the legend's corners, whether marked or auto-detected.
- A marked or detected legend is masked by itself: "that is half the point." Mask an area stays for everything
  else that is not data (text, arrows, insets, reference lines). Marking the legend by hand is the same
  corner-to-corner drag as Mask an area and crop.
- A masked area and a marked legend are shaded in different colours, so they can be told apart.
- If Auto detect legend finds nothing, a warning with the triangle in the bottom bar says so, as the calibration
  card's detection does.
- Selecting a legend corner lets the user edit it while the Legend card is open; with the card closed it cannot
  be selected or changed. The same as the calibration card.
